# Blahut-Arimoto Algorithm — Implementation Notes

This documents the BA implementation in `encoder/quantization/core_vq.py`
(`_ba_kmeanspp_init`, `_ba_pass`, `_ba_solve`) as used in this project.

---

## What the algorithm does

BA solves the **rate-distortion optimization problem**: given a dataset of vectors
and a target trade-off parameter $\beta$, find a codebook of $M$ codewords that
minimizes the Lagrangian

$$\mathcal{L} = D - \frac{1}{\beta} R$$

where $D$ is expected squared distortion and $R$ is the mutual information (rate
in bits) between the data and the codeword assignments. Higher $\beta$ pushes
toward lower distortion at the cost of higher rate; lower $\beta$ does the
opposite.

The key difference from standard k-means:
- k-means uses **hard** (winner-take-all) assignments and a uniform prior over
  codewords.
- BA uses **soft** (probabilistic) assignments weighted by
  $\exp(-\beta \cdot d)$, and jointly optimizes the prior $q$ over codewords.
  This allows it to trace the full R(D) frontier by varying $\beta$.

---

## Underlying probabilistic model

BA can be understood as **EM on a mixture of isotropic Gaussians** where all
components share the same covariance controlled by $\beta$.

We model the data as being generated by a mixture:

$$p(z) = \sum_{m=1}^{M} q(m)\, p(z \mid m)$$

where each component is a Gaussian centered at codeword $y_m$ with a shared,
isotropic covariance:

$$p(z \mid m) = \mathcal{N}\!\left(z;\; y_m,\; \tfrac{1}{2\beta}\, I\right) = \frac{1}{(2\pi / 2\beta)^{k/2}} \exp\!\bigl(-\beta\, \|z - y_m\|^2\bigr)$$

The parameter $\beta$ acts as an inverse variance: high $\beta$ means tight
clusters (small variance $\sigma^2 = 1/2\beta$), low $\beta$ means diffuse
clusters.

When we apply Bayes' rule to get the posterior assignment probability, the
Gaussian normalization constant $(2\pi / 2\beta)^{-k/2}$ is identical for every
component $m$ (since they all share the same covariance), so it cancels between
numerator and denominator:

$$p(m \mid z_n) = \frac{q(m)\, p(z_n \mid m)}{\sum_{m'} q(m')\, p(z_n \mid m')} = \frac{q(m)\, e^{-\beta\, d_{nm}}}{\sum_{m'} q(m')\, e^{-\beta\, d_{nm'}}}$$

This is why the code and the equations below write $p(z_n \mid m)$ as simply
$e^{-\beta\, d_{nm}}$ — it is the Gaussian likelihood up to a constant that
always cancels in the posterior. It is not a normalized probability on its own.

With this model in place, the algorithm alternates exactly like EM:
- **E-step (inner loop):** compute the posterior $p(m \mid z_n)$ and update the
  prior $q(m)$, holding codewords $Y$ fixed.
- **M-step (outer loop):** update each codeword $y_m$ to the posterior-weighted
  centroid of the data, holding $q$ fixed.

The only structural difference from textbook Gaussian-mixture EM is that here the
E-step iterates $q$ to convergence (because the optimal $q$ depends on itself
through the normalization), rather than computing it in a single closed-form
pass.

## Notation

| Symbol | Meaning |
|---|---|
| $N$ | Number of data points (latent vectors) in the dataset |
| $k$ | Dimensionality of each latent vector (512 in this project, or lower after PCA reduction) |
| $z_n \in \mathbb{R}^k$ | The $n$-th data point; a single pre-VQ latent vector |
| $Z \in \mathbb{R}^{N \times k}$ | The full dataset matrix, rows are $z_n$ |
| $M$ | Number of codewords in the codebook |
| $y_m \in \mathbb{R}^k$ | The $m$-th codeword (centroid); what we are optimising |
| $Y \in \mathbb{R}^{M \times k}$ | The codebook matrix, rows are $y_m$ |
| $q(m)$ | Prior probability of codeword $m$; a learned scalar weight summing to 1 over $m$ |
| $p(m \mid z_n)$ | Posterior probability that data point $z_n$ is assigned to codeword $m$ |
| $d_{nm} = \|z_n - y_m\|^2$ | Squared Euclidean distance from data point $n$ to codeword $m$ |
| $\beta > 0$ | Inverse temperature / Lagrange multiplier controlling the rate-distortion trade-off |
| $D$ | Expected distortion: $\mathbb{E}_{n,m}[p(m \mid z_n)\, d_{nm}]$ |
| $R$ | Rate: mutual information $I(Z;\, Y)$ between data and codeword assignments, in bits |

## Initialization: `_ba_kmeanspp_init`

Before the main loop, codewords are seeded using **KMeans++**:

1. Pick the first codeword uniformly at random from the data.
2. For each subsequent codeword $m$, compute for every data point its squared
   distance to the nearest already-chosen codeword:

$$d^\star_n = \min_{j < m} \|z_n - y_j\|^2$$

   Then sample the next codeword with probability proportional to $d^\star_n$:

$$P(\text{select } z_n) = \frac{d^\star_n}{\sum_{n'} d^\star_{n'}}$$

This spreads the initial codewords across the data distribution and gives BA a
much better starting point than a random draw.

---

## Per-iteration breakdown

The algorithm has a two-level loop: an **outer loop** (centroid updates) and an
**inner loop** (prior `q` updates).

### Inner loop — `_ba_pass` (E-step: update `q`)

Each call to `_ba_pass` does one pass over the full dataset in chunks of
`chunk_N` vectors. For each chunk:

**1. Compute squared distances** from every data point $z_n$ to every codeword $y_m$:

$$d_{nm} = \|z_n - y_m\|^2$$

Computed efficiently as $\|z\|^2 + \|y\|^2 - 2\, z \cdot Y^\top$.

**2. Compute soft assignment probabilities** (Boltzmann distribution):

$$p(m \mid z_n) = \frac{q(m)\, p(z_n \mid m)}{p(z_n)} = \frac{q(m)\, e^{-\beta\, d_{nm}}}{\sum_{m'} q(m')\, e^{-\beta\, d_{nm'}}}$$

Implemented in log-space for numerical stability:

$$\log p(m \mid z_n) = \log q(m) - \beta\, d_{nm} - \log \sum_{m'} e^{\log q(m') - \beta\, d_{nm'}}$$

The distribution is temperature-controlled by $\beta$. As $\beta \to \infty$ this collapses
to a hard nearest-neighbor assignment (standard k-means). At low $\beta$ all
codewords get nearly equal weight.

**3. Accumulate statistics** across the chunk:

- $\texttt{q\_acc}[m] \mathrel{+}= \sum_n p(m \mid z_n)$ — marginal usage of codeword $m$
- $\texttt{num}[m] \mathrel{+}= \sum_n p(m \mid z_n)\, z_n$ — probability-weighted sum of data points
- $\texttt{den}[m] \mathrel{+}= \sum_n p(m \mid z_n)$ — total weight for codeword $m$
- $D \mathrel{+}= \sum_{n,m} p(m \mid z_n)\, d_{nm}$ — contribution to expected distortion
- $I \mathrel{+}= \sum_{n,m} p(m \mid z_n)\bigl[\log p(m \mid z_n) - \log q(m)\bigr]$ — KL term (mutual information)

**4. Update prior**:

$$q_{\text{new}}(m) = \mathbb{E}_{z}\bigl[p(m \mid z)\bigr] = \frac{1}{N} \sum_n p(m \mid z_n)$$

This is the marginal assignment probability — codewords that are heavily used
get higher prior weight.

**5. Convergence check**:

$$\delta = \max_m \lvert q_{\text{new}}(m) - q(m) \rvert$$

If $\delta < \texttt{tol\_q}$, the inner loop breaks early.

### Outer loop — `_ba_solve` (M-step: update centroids `Y`)

After each inner loop converges (or hits `inner_iters`), the codewords are
moved to their soft-weighted centroids:

$$y_m \leftarrow \mathbb{E}[z \mid m] = \frac{\sum_n p(m \mid z_n)\, z_n}{\sum_n p(m \mid z_n)}$$

This is the **M-step**: each codeword moves to the soft center of mass of the
data points assigned to it. As $\beta \to \infty$, this reduces exactly to the
k-means centroid update.

After updating $Y$, convergence of the outer loop is also checked against
$\delta < 10^{-6}$.

A final `_ba_pass` is run after the loop exits to report clean `D` and `R_bits`
values computed at the final `(Y, q)`.

---

## Summary: what changes each iteration

| What | Inner loop | Outer loop |
|---|---|---|
| `q` (prior) | Updated every inner pass | Held fixed while centroids update |
| `Y` (centroids) | Held fixed while `q` updates | Updated after inner loop converges |
| `D`, `R_bits` | Recomputed each pass | Reported from final pass |

The alternating structure is analogous to EM: the inner loop is the E-step
(recompute posterior given fixed model), and the outer centroid update is the
M-step (update model given fixed posterior). Unlike EM for Gaussians, BA's
E-step iterates `q` until convergence rather than computing it in closed form,
because the optimal `q` depends on `q` itself through the normalization.

---

## The `beta` parameter

`beta` is the Lagrange multiplier controlling the rate-distortion trade-off:

- **High $\beta$**: assignments are nearly hard (low temperature), codewords pack
  tightly around data clusters, low $D$, high $R$.
- **Low $\beta$**: assignments are soft and diffuse, codewords spread more
  uniformly, high $D$, low $R$.

The optimal rate-distortion trade-off at a given $\beta$ satisfies:

$$R^*(\beta) = \beta \frac{\partial D^*}{\partial \beta}$$

Running `ba_sweep` or the beta-sweep notebooks at multiple values of $\beta$
traces out the R(D) frontier — the set of Pareto-optimal $(D, R)$ points.

## Code

```
_BA_LN2 = math.log(2.0)


@torch.no_grad()
def _ba_kmeanspp_init(Z: torch.Tensor, M: int, seed: int = 0, chunk: int = 8192) -> torch.Tensor:
    """KMeans++ seeding. Z: (N, k) → Y: (M, k)."""
    N, k = Z.shape
    g = torch.Generator(device=Z.device).manual_seed(seed)
    Y = torch.empty(M, k, device=Z.device)
    Y[0] = Z[torch.randint(0, N, (1,), generator=g, device=Z.device)]
    dmin = torch.full((N,), float("inf"), device=Z.device)
    for m in range(1, M):
        c = Y[m - 1:m]
        for s in range(0, N, chunk):
            d = ((Z[s:s + chunk] - c) ** 2).sum(-1)
            dmin[s:s + chunk] = torch.minimum(dmin[s:s + chunk], d)
        probs = dmin.clamp(min=1e-12)
        Y[m] = Z[torch.multinomial(probs / probs.sum(), 1, generator=g)]
        # if m % 512 == 0:
        #     print(f"  kmeans++ init: {m}/{M}")
    return Y


@torch.no_grad()
def _ba_pass(
    Z: torch.Tensor, Y: torch.Tensor, logq: torch.Tensor, beta: float, chunk_N: int = 2048
):
    """One BA E-step. Returns (q_new, D, R_bits, num, den)."""
    N, k = Z.shape
    M = Y.shape[0]
    y2 = (Y * Y).sum(-1)

    q_acc = torch.zeros(M, device=Z.device)
    num = torch.zeros(M, k, device=Z.device)
    den = torch.zeros(M, device=Z.device)
    D_sum = 0.0
    I_sum = 0.0

    for s in range(0, N, chunk_N):
        z = Z[s:s + chunk_N]
        d = ((z * z).sum(-1, keepdim=True) + y2 - 2 * z @ Y.t()).clamp(min=0)
        logits = logq - beta * d
        lse = torch.logsumexp(logits, dim=1, keepdim=True)
        logp = logits - lse
        p = torch.exp(logp)

        q_acc += p.sum(0)
        num += p.t() @ z
        den += p.sum(0)
        D_sum += (p * d).sum().item()
        I_sum += (p * (logp - logq)).sum().item()

    q_new = (q_acc / N).clamp(min=1e-30)
    return q_new, D_sum / N, (I_sum / N) / _BA_LN2, num, den


@torch.no_grad()
def _ba_solve(
    Z: torch.Tensor,
    beta: float,
    M: int,
    Y_init: torch.Tensor,
    outer_iters: int = 25,
    inner_iters: int = 5,
    tol_q: float = 1e-6,
    chunk_N: int = 2048,
    verbose: bool = False,
) -> dict:
    """Blahut-Arimoto solver. Returns dict: Y, q, logq, D, R_bits, elapsed_s, converged, n_outer_iters, final_delta."""
    t_start = time.time()
    logq = torch.full((M,), -math.log(M), device=Z.device)
    Y = Y_init.clone()
    delta = float("inf")

    for t in range(outer_iters):
        for _ in range(inner_iters):
            q_new, D, R_bits, num, den = _ba_pass(Z, Y, logq, beta, chunk_N)
            delta = (q_new - torch.exp(logq)).abs().max().item()
            logq = torch.log(q_new)
            if delta < tol_q:
                break
        Y = (num / (den.unsqueeze(1) + 1e-12)).contiguous()
        if verbose:
            print(f"  [outer {t:02d}] D={D:.6f}  R={R_bits:.4f} bits  |Δq|={delta:.2e}")
        if delta < 1e-6:
            break

    converged = delta < 1e-6
    n_outer_iters = t + 1  # t is 0-indexed; +1 gives number of outer iters completed

    _, D, R_bits, _, _ = _ba_pass(Z, Y, logq, beta, chunk_N)
    return {"Y": Y, "q": q_new, "logq": logq, "D": float(D), "R_bits": float(R_bits),
            "elapsed_s": time.time() - t_start,
            "converged": converged, "n_outer_iters": n_outer_iters, "final_delta": float(delta)}
```
